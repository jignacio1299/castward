# Castward

Castward is a simple browser-based running planner. It helps you choose a running time, review the weather for the full run, plan what to wear, and save notes about what worked.

This prototype uses plain HTML, CSS, and JavaScript with built-in demo weather scenarios.

## Features

- Plan a run by location, start time, and duration
- Review temperature, rain chance, wind, and hourly forecasts
- Compare different start times
- Choose clothing for running or run-walk activities
- Adjust clothing recommendations for warmer or cooler preferences
- Save a clothing plan
- Add personal session notes and feeling tags
- Try deterministic weather scenarios for demos
- Switch between Fahrenheit and Celsius
- Optionally request live hourly weather from the National Weather Service
